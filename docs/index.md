# Egg Rivals

Egg Rivals is a Roblox speed-heist, elemental-pet collection, living-ranch, social-economy, and opt-in rivalry game.

The current engineering candidate is `EGG-RIVALS-0.4.0-rc1`: **77/77** exact-source checks passed in a real two-client Studio regression.

Status: **ENGINEERING CANDIDATE VERIFIED; HUMAN PRESENTATION ACCEPTANCE PENDING**.

The previous `MOONWOOD-0.3.2-r2` candidate remains preserved as historical 24/24 baseline evidence.

## Core loop

`train -> steal -> escape -> choose element -> hatch -> collect -> earn -> upgrade -> compete`

## Current gate

Owner playtesting is the active gate. Record observations and decisions in [0.4.0 Owner Playtest](PLAYTEST_0.4.0.md).
