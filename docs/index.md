# Egg Rivals

Egg Rivals is a Roblox speed-heist, elemental-pet collection, living-ranch, social-economy, and opt-in rivalry game.

The current verified engineering baseline is `MOONWOOD-0.3.2-r2`: 24/24 two-client Studio checks passed. Human presentation and gameplay-feel acceptance remains a separate gate.

## Core loop

`train -> steal -> escape -> choose element -> hatch -> collect -> earn -> upgrade -> compete`
