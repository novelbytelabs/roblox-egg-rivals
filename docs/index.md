# Egg Rivals

Egg Rivals is a Roblox speed-heist, pet-collection, base-building, and opt-in duel game.

The current engineering baseline is `MOONWOOD-0.3.2-r2`. It passed 24/24 two-client Roblox Studio engine checks; human presentation and gameplay-feel review remains open.

## Core loop

`train -> steal an egg -> escape -> choose an element -> hatch a pet -> earn -> upgrade -> collect -> compete`
