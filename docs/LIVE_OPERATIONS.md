# Egg Rivals — Live Operations

Status: approved compatible direction; implementation belongs after the core game is stable.

Live events should temporarily intensify the existing world without invalidating permanent progression.

## Night

Night is the primary world-state event and has its own canonical specification in `NIGHT_SYSTEM.md`.

## Approved event directions

- **Egg Rush** — temporarily increases egg availability / activity under rules appropriate to the current zone.
- **Speed Surge** — temporary training-rate event.
- **Giant Egg Invasion** — shared high-value target / server spectacle.
- **Rare Rain** — short rarity-table event with stronger visual presentation.
- **Controlled admin events** — playful server-wide events with explicit limits.

"Admin abuse" style presentation may be playful, but permanent inventory and economy integrity remain server-authoritative.

## Live-ops principles

- events should bring players together;
- event rewards must not make ordinary progression meaningless;
- server state must clearly signal start/end;
- event-specific visual language should be immediately readable;
- temporary boosts expire deterministically;
- rare events should feel exciting because they are uncommon;
- avoid arbitrary permanent grants that damage the collection economy.

Night remains the highest-priority live-event presentation target.
